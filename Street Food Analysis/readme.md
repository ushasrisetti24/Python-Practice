# Street Food Analysis

## Dataset Source
This project uses the Global Street Food Dataset from Kaggle.

Source reference used in the notebook:
- Kaggle dataset: benjnb/global-street-food-dataset
- Accessed through KaggleHub in the project notebook

## About the Dataset
The dataset contains street food information collected across multiple countries and cities. It includes details such as:
- Country
- Region/City
- Dish Name
- Typical Price (USD)
- Ingredients

This dataset is useful for exploring food pricing, ingredient patterns, diversity of dishes, and geographic trends in street food offerings.

## Project Goal
The notebook analyzes the dataset to answer a range of food and market questions, including pricing, ingredient frequency, country comparisons, and city-level dish patterns.
